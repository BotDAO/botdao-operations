## Qualified Referee Requirements

A referee must complete ALL of the following:

1. **Sign up** using referral link or code
2. **Deposit** at least $100 within 7 days of registration

## Bybit Affiliate Program (Upgrade Path)

The Affiliate Program is a separate, higher-tier program from the Referral Program. If BotDAO scales enough referrals, upgrading to Affiliate may make sense — but switching forfeits Referral Program rewards.

### Key Differences from Referral Program

| Feature | Referral Program | Affiliate Program |
|---------|-----------------|-------------------|
| Commission basis | Fixed reward per task | % of trading fee revenue (taker volume) |
| Commission duration | Per-task, one-time | Lifetime commissions |
| Payout schedule | Claim from Rewards Hub | Daily by 4AM UTC |
| Support | Self-service | Dedicated account manager |
| ID verification | Required (Lv. 1) | Not required |
| Cost to join | Free | Free |
| Referral limit | Unlimited | Unlimited |
| Best for | Small-medium scale | High-volume, content creators, influencers |

### How It Works

1. Apply at affiliates.bybit.com
2. Fill in questionnaire about yourself and promotion plans
3. Team evaluates application against criteria
4. If approved: get access to affiliate backend dashboard
5. Commissions calculated in real-time on referee trading fees (taker volume)
6. Daily payouts by 4AM UTC
7. Withdraw earnings instantly to Bybit trading account

### Who Qualifies

Bloggers, influencers, publishers, content creators with a qualifying website, trading software or mobile app, and Bybit customers with an extensive network of traders.

### Dashboard Features

- **Commissions page:** View all earnings details
- **Clients page:** Full list of referrals with volume, deposits, rebates
- **Withdraw:** Instant withdrawal to Bybit trading account

### Important: Switching Warning

If you switch from Referral Program to Affiliate Program:
- You **lose** all Referral Program rewards going forward
- Your existing referees can still claim their rewards if they meet task requirements
- This is a one-way decision — consider carefully
