# Template: Discord Announcement

## Structure

- **Headline:** Bold, one line summary
- **Body:** 2-3 short paragraphs. More detail than X but still concise.
- **Links:** Relevant links to sources, on-chain data, or full thread
- **Tags:** @here only for major milestones. @everyone never.

## Rules

- Markdown formatting allowed (bold, links, code blocks for data)
- More conversational than X — Discord audience expects slightly warmer tone
- Include source links for any data claims
- Follow voice-guidelines.md tone
