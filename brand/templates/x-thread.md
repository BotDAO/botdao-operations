# Template: X Thread

## Structure

- **Tweet 1 (Hook):** State the headline fact or insight. Make it standalone — most people only see this tweet.
- **Tweets 2-N (Body):** One idea per tweet. Use data points, not claims. Keep each tweet under 280 chars.
- **Final Tweet (CTA):** Tag @0xMantle. Include one relevant hashtag. Invite engagement (question, not command).

## Rules

- Max 10 tweets per thread
- No emojis as substitutes for substance (one relevant emoji per tweet max)
- Every claim backed by a data point or source
- Follow voice-guidelines.md tone for the context
- End with #MantleNetwork at minimum
