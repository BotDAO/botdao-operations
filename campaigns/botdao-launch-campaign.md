# BotDAO Launch Campaign: Mantle Squad Bounty

## Campaign Overview

**What:** A 16-day organic campaign to build awareness of BotDAO as an AI-agent-powered marketing DAO on Mantle Network, culminating in the Mantle Squad Bounty submission (Mar 31).

**Why:** BotDAO needs visibility in the Mantle community before the submission deadline. Judges should already know who we are. Community members should be following the build in real time. The Bybit referral campaign runs as a live demo of what the agents can do.

**How:** Build in public on X/Twitter, maintain a polished GitHub presence, and engage the Mantle Discord community — all zero-budget, all organic.

1. **Primary — Awareness:** Reach 500+ unique accounts on X/Twitter with BotDAO content by March 31

## Core Message

**One-liner:** BotDAO is a swarm of AI agents that runs marketing operations autonomously on Mantle — from finding stories to publishing content to managing a treasury.

**Supporting messages:**

1. **"AI agents, not chatbots."** BotDAO's six agents make decisions, score their own work, and hand off tasks to each other through structured files. This isn't a wrapper around ChatGPT — it's an autonomous operating system for marketing.

2. **"Built on Mantle, for Mantle."** Every agent is tuned to the Mantle ecosystem. Scout monitors Mantle-specific signals. Content writes about Mantle DeFi. Treasury manages $MNT. This isn't a generic tool — it's purpose-built.

3. **"The agents are running right now."** This isn't a whitepaper. The content you're reading was found by Scout, written by Content, and published by Distribution. The system is live.

4. **"Open architecture, modular design."** Six agents, file-based handoffs, MCP server integrations, governance-controlled parameters. Every piece is documented, auditable, and extensible.

## Key Talking Points for Judges

When creating content, weave these themes in naturally:

1. **Live system, not a prototype.** The agents are running and producing real output during the contest period. Link to actual agent-generated content as proof.

2. **Mantle-native.** Every agent is configured for the Mantle ecosystem — Scout monitors Mantle accounts, Content writes about Mantle DeFi, Treasury manages $MNT.

3. **Revenue model demonstrated.** The Bybit referral campaign shows BotDAO can generate real revenue autonomously. Even a few signups prove the concept.

4. **Governance-controlled.** Parameters are managed through the governance repo. Config changes flow through PRs. This is a DAO, not a script.

5. **Extensible architecture.** MCP servers, file-based handoffs, and modular agent configs mean the system can grow beyond marketing — same pattern works for any multi-agent workflow.
